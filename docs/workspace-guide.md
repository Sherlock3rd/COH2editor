# COH2 地图制作助手工作区指南

## 定位

本项目是 COH2 地图制作的策划与工具辅助工作区，当前环境支持：

- World Builder 环境检查与启动。
- 地图资料、工作副本与生成产物分区管理。
- 后续地图结构检查、点位/路径数据分析、日志诊断和交付检查。

具体地图设计目标、地图规模、玩家人数、模式、资源与胜利条件尚未确认，不在本次环境部署中预设。

## 目录约定

| 目录 | 用途 | 默认处理方式 |
| --- | --- | --- |
| `workspace/maps/` | 自主制作地图的工作副本 | 不自动提交，不覆盖来源文件 |
| `workspace/references/` | 截图、草图、规则参考和外部资料 | 只读使用，除非用户要求整理 |
| `artifacts/reports/` | 检查报告、诊断结论 | 可重新生成 |
| `artifacts/previews/` | 地图预览、可视化结果 | 可重新生成 |
| `artifacts/exports/` | 临时导出和打包候选 | 发布前必须人工确认 |
| `config/environment.json` | 本机 COH2 路径配置 | 路径变化时更新并复检 |

## 已识别的本机入口

- 游戏安装目录、World Builder、用户地图目录和日志目录由本机 `config/environment.json` 记录。
- 仓库只提供 `config/environment.example.json`，不会提交个人机器的绝对路径。
- World Builder 的标准可执行文件名为 `WorldBuilder_CoH_2.exe`。

填写本机配置后，可运行 `scripts/check-environment.ps1` 重新确认。

## 标准工作流

1. 明确本次任务是环境、诊断、地图设计、地图修改还是发布检查。
2. 读取项目规则与相关错题记录。
3. 对源地图、参考文件和目标产物做只读盘点。
4. 涉及地图设计或交互意图时，先取得书面确认。
5. 在工作副本上处理；生成结果进入 `artifacts/`。
6. 对数据数量、坐标系、依赖加载顺序和生成时间进行复核。
7. 需要写回、覆盖、打包或发布时，再单独确认目标与范围。

## 地图数据防呆

- 不把“更换源文件路径”理解成“编辑源数据”。
- 地图底图或导航数据变化后，先重建空间索引，再分类或统计点位。
- 有依赖的多份地图数据按顺序加载，避免旧索引与新数据混用。
- 正式预览或报告生成前，核对源数据与中间分析数据的数量和更新时间。
- 大地图可视化优化不得以抽样方式静默丢失分区、轮廓或关键点位。
