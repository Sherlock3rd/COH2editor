# COH2 World Builder 生产阶段规范

本规范统一进度口径。阶段只能在全部退出条件满足且已保存后标记为通过；未保存操作必须单独列出。

## G0 场景正确

- 正式名称、目录、地形尺寸、可玩区尺寸、cell size 和玩家数与已确认设计一致。
- 完整场景 bundle 能保存、关闭并重新打开。
- 修改既有场景前已有可恢复备份。

## G1 点位完整

- 两个完整出生包已整体移动到设计位置，玩家/队伍归属正确。
- VP、燃料、弹药和标准领地点数量、类型及位置与设计数据一致。
- 基地有建造空间、进入点和安全出口。

## G2 领地连通

- sector 覆盖可玩区且无孤岛、重叠错误或错误邻接。
- 双方 HQ 到自然资源存在有效补给链。
- cutoff 有战术意义且存在反制路线。

## G3 路线可走

- 中心、左翼、右翼三条路线在灰盒中可识别。
- 步兵能通过所有设计路线；主车辆路线满足中型车辆通行宽度。
- 基地出口和关键目标不存在隐藏阻挡或单点封锁。

## G4 边界有效

- playable area、soft map、interactivity stage 5 和 impass map 一致。
- 单位不能离开预定可玩区，关键路线未被边界误切断。

## G5 最小战斗灰盒

- 道路、最少量掩体和 LOS blocker 已表达三路职责。
- 关键目标至少有两个进攻方向，没有直接压制敌方基地的永久强点。
- 未投入会妨碍路线调整的详细美术。

## G6 编辑器与产物通过

- World Builder Error Messages 无阻断项。
- 场景保存、关闭、重开成功。
- 必需 sidecars、战术地图和发布所需产物已生成并验证。

## G7 游戏内通过

- 完成 `acceptance-spec.md` 的真实 1v1 AI 验收。
- 双方开局、占点、补给、资源、VP、AI 行为和车辆路线均通过。
- 只有 G7 通过后，交付状态才可写为“可玩地图”。

## 状态报告格式

每次进度报告必须包含：

- 当前阶段：例如 `G2 进行中`。
- 最后已保存阶段：例如 `G1 已保存`。
- 未保存操作：无则写“无”。
- 证据类型：编辑器 / 文件产物 / 游戏内。
- 下一阻断项：只写阻止进入下一阶段的事项。

禁止使用“基本完成”“已经打开”“已经保存”等表述替代阶段结论。
