# World Builder 空白骨架被误报为可玩地图

## 基本信息

- 日期：2026-08-19
- 分类：design / validation / world-builder
- 关联需求：COH2 1v1 地图生成

## 客观事实

- 只创建了空白地形和自动生成的双人出生位。
- 未放置胜利点、资源点、标准领地点，未建立领地补给链、路径、掩体和地图边界。
- 未生成完整场景产物，也未在游戏内运行 1v1 AI 对局。
- 回复中使用了“地图骨架”描述，但此前执行方向把保存 `.sgb` 当作主要进度，操作迟缓且离可玩目标很远。

## 原因判断

- 未在操作前读取 World Builder 官方制作流程和多人地图必需对象。
- 没有先定义“可玩”的验收门槛。
- 过度依赖逐像素 UI 操作，没有按灰盒顺序、快捷键和可复用起始包组织工作。

## 修复与验证

- 建立 `skills/coh2-world-builder/` 与 `spec/coh2-world-builder/`。
- 将游戏内 1v1 AI 测试设为完成前强制门槛。
- 后续先完成路线、领地、点位和灰盒，再做装饰。
