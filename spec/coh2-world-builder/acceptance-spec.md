# COH2 多人地图验收规范

本规范对应 `production-gates-spec.md` 的 G6 与 G7。G0–G5 的阶段结论不能替代本验收。

## A. 编辑器静态检查

- [ ] 场景位于模块允许的 `Data\Scenarios\<folder>\<same-name>.sgb` 路径。
- [ ] 未覆盖已有地图。
- [ ] 两个起始包完整，玩家/队伍归属不同且处于正确起始领地。
- [ ] VP、燃料、弹药、标准领地点数量与设计图一致。
- [ ] 领地覆盖可玩区，补给链没有孤岛或错误相邻。
- [ ] 可玩边界、interactivity stage、impass map 与软边一致。
- [ ] World Builder Error 列表无阻断项。
- [ ] 全局视图能直接辨认左侧林篱农路、中央欧洲小镇、右侧果园乡道和南北农业坡地。
- [ ] 地形存在规划高差，主路/基地出口坡面平滑，制高点不压制基地。
- [ ] 建筑群使用正式资源并形成院落生态；不存在占位方块或孤立撒点式建筑。
- [ ] 区域交界有清晰视觉语言，同时保留至少两处可用进攻/穿越口。

## B. 生成产物检查

- [ ] `.sgb`、`.info`、`.options`、`.scenariomarker`、`_id.scar` 等必需产物存在。
- [ ] `_mm.tga`/预览与 top-down 产物按当前发布路径生成。
- [ ] 320 × 320 地图的 `_mm.tga` 为 768 × 768、32-bit 未压缩 BGRA、全不透明，文件大小为 `2,359,314` bytes。
- [ ] World Builder 场景身份、`.info` 的 `scenarioname`、basename 与归档 TOC 路径一致；未通过手改 `.info` 制造伪版本身份。
- [ ] 场景能由 Mod Builder/目标模块正确构建或打包。
- [ ] `Archive.exe -t` 通过，且 `Archive.exe -l` 中关键文件尺寸与当前源 bundle 一致。
- [ ] 仓库 SGB 与编辑源 SGB 的 SHA-256 一致；仓库 SGA 与运行目录活动 SGA 的 SHA-256 一致。

## C. 游戏内 1v1 验收

- [ ] 地图出现在正确的自定义游戏/Modding Hub 列表。
- [ ] 玩家与 AI 均能进入，双方 HQ/初始单位正常。
- [ ] 双方能离开基地并沿三条主路线移动。
- [ ] 每个领地点都可占领，资源点连接 HQ 后产生正确资源。
- [ ] 三个 VP 可占领并触发 VP ticker/drain。
- [ ] AI 能离开基地、占点并参与战斗。
- [ ] 步兵与至少一种中型车辆能通过所有设计主路，不被隐藏阻挡卡死。
- [ ] 基地出口没有立即受到远程压制或被单物件封死。
- [ ] 交换出生侧后未发现明显单边优势。
- [ ] 两端出生相机均看不到环形盆地、遮挡 HQ 的近景土丘或只有单一陡坡出口；基地平台与第一段主路之间存在连续平滑坡面。
- [ ] 中央镇区在游戏相机内形成可辨的街道/院落组团，而不是只有孤立建筑与大面积空地；同时中央 VP 保持至少 16 m 战斗净空。

## D. 交付证据

- 编辑器证据：场景标题/路径、领地图层、点位与错误列表。
- 构建证据：产物清单和构建成功结果。
- 运行证据：自定义房间加载、双方开局、占点/资源、VP 计分、AI/车辆路径。

仅 A 通过不能称为可玩；至少 A、B、C 全部通过后才能提交“可玩地图”结论。

## E. 状态真实性

- [ ] 报告标明当前 G0–G7 阶段和最后已保存阶段。
- [ ] 未保存的 UI 操作与已保存结果分开记录。
- [ ] “能打开”“已保存”“尺寸正确”“存在自动出生包”没有被描述为可玩或接近验收完成。
- [ ] 编辑器、文件产物、游戏内证据没有相互替代。
- [ ] 自动化因用户输入、Escape、窗口遮挡或崩溃中断时，已记录准确恢复点，并在恢复后重新读取窗口、场景和编辑模式。
