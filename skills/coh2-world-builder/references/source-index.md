# Source index

Use authoritative sources first. Re-check URLs and the installed editor when updating this knowledge.

## Primary and official-partner sources

- [Essence Engine Wiki home](https://modding.companyofheroes.com/) — Relic-partnered COH2 modding documentation hub.
- [World Builder](https://modding.companyofheroes.com/world-builder) — launcher and UI entrypoint.
- [Dressing a Map tutorial](https://modding.companyofheroes.com/deleted%3Aworld-builder-tutorial) — multiplayer scenario creation, player placement, terrain, roads, splines, buildings, interactivity border, save/playtest workflow.
- [Scenario format](https://modding.companyofheroes.com/scenario) — required and optional files generated around an `.sgb`.
- [Mission creation tutorial](https://modding.companyofheroes.com/single-player-missions) — object placement and `starting_position_shared_territory` behavior; use only the object mechanics relevant to multiplayer.
- [Mod Builder](https://modding.companyofheroes.com/mod-builder) — tool installation, configuration, and scenario-pack build context.
- [COH2 manual](https://www.feralinteractive.com/en/manuals/companyofheroes2/latest/steam/) — territory supply, capture points, resources, victory conditions, and gameplay purpose.

## Secondary practical sources

- [Making a Map in 20 Minutes or Less](https://www.coh2.org/topic/100211/making-a-map-in-20-minutes-or-less) — rapid graybox sequence and commonly used gameplay entities. Verify names in the installed Object Placement tree.
- [Worldbuilding with WhiteFlash](https://www.coh2.org/guides/5478/worldbuilding-with-whiteflash) — lane, cutoff, VP, and attack-option design reasoning.
- [Capturable Area](https://www.coh2.org/guides/17057/worldbuilder-totw-12-capturable-area) — capture-zone positioning around territory points.

## GitHub reconnaissance (2026-08-19)

No ready-made Codex Skill or complete automated COH2 World Builder map generator was found through GitHub repository/code search. Useful partial references:

- [cioudfox/CoH2-modding-templates](https://github.com/cioudfox/CoH2-modding-templates) — scenario and mod metadata examples.
- [Officute/CoH2-all-scar-files-mission-scripts](https://github.com/Officute/CoH2-all-scar-files-mission-scripts) — SCAR/win-condition reference corpus.
- [MetaIdea/COH2-Mods](https://github.com/MetaIdea/COH2-Mods) — multiple COH2 mod structures and win conditions.
- [Janne252/coh2-replay-enhancements](https://github.com/Janne252/coh2-replay-enhancements) — test scenario metadata examples.
- [BattlegroundsCoH/coh-battlegrounds](https://github.com/BattlegroundsCoH/coh-battlegrounds) — map/minimap analysis code, not a World Builder replacement.

Do not copy repositories into the project or publish derived work without checking license and user intent.
