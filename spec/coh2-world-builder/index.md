# COH2 World Builder Spec 库

本目录是 COH2 多人地图的项目级验收标准源。

- `playable-1v1-map-spec.md`：1v1 可玩地图的结构与设计底线。
- `fast-production-spec.md`：先灰盒、后美术的快速生产流程。
- `acceptance-spec.md`：编辑器、构建产物与游戏内验收。
- `production-gates-spec.md`：G0–G7 生产阶段、状态命名和阶段退出条件。

操作方法与来源索引位于 `skills/coh2-world-builder/`。规范决定“什么算完成”，Skill 决定“如何完成”。
